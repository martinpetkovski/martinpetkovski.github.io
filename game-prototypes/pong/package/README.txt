PONG (2013) - Windows x64
=========================

Run pong.exe to start the game. Keep pong.exe, the DLL files, and all media
files together in this directory.

Requirements
------------
- 64-bit Windows 10 or Windows 11
- A display, keyboard, and audio output

Controls
--------
Single player:
- Up / Down arrows: move the paddle
- Space: launch the ball
- Escape: return to the menu

Two players:
- W / S: move the left paddle
- Up / Down arrows: move the right paddle
- Space: launch the first ball
- Escape: return to the menu

The game starts in fullscreen using the desktop resolution.
